# 🔨 打地鼠

难度递增的限时点击小游戏。手机竖屏即玩，纯前端（Phaser 3.90.0），无构建。

## 玩法
- 限时 **30 秒**，点击从洞里冒头的**好地鼠**（🔵 +1）。
- 点错**炸弹**（💣）-2 分并扣 2 秒。
- **金币**：每 10 分得 1 金币，金币买道具（5 金币/个，10s 冷却）：
  - 🐌 **减速**：3 秒内地鼠停留更久，好点
  - ✋ **双倍**：3 秒内得分 ×2
  - 💥 **清屏**：瞬间移除所有炸弹 + 4 秒
- **等级**：每 50 分升 1 级，地鼠更快、炸弹占比更高、同屏更多。
- **存档**：localStorage 存最高分 / 金币（跨局累积）。
